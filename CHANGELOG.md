### Added

- Standalone offline Rust CLI with guarded SQLite snapshots and per-file atomic migration execution.
- Metadata-driven schema and row-survival analysis, foreign-key/integrity checks and workload query-plan comparison.
- Seventeen stable rules with configurable severities, terminal/JSON/Markdown reports and GitHub Actions integration.
- Tracking-aware migration discovery, explicit schema boundaries and basic Wrangler TOML configuration.
- Reproducible fixtures, CLI/integration tests, architecture/rule documentation and a locally testable orders Worker example.
